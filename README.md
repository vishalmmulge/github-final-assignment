# Simple Interest Calculator

A simple shell script to calculate simple interest.

## Description

This project provides a shell script `simple-interest.sh` that calculates simple interest given the principal amount, annual rate of interest, and time period in years.

## Formula

```
Simple Interest = (Principal * Rate * Time) / 100
```

## Usage

```bash
bash simple-interest.sh
```

The script will prompt you to enter:
- Principal amount
- Annual rate of interest (%)
- Time period (in years)
